# Reglas de la carpeta `commands`

- En esta carpeta van skills diseñados para poder usarse también como comandos invocables.
- Cada skill debe incluir una descripción clara de qué hace, para qué sirve y cuándo se usa.
- Cada skill de esta carpeta debe poder invocarse también como comando para flujos operativos repetibles.
- Mantener consistencia con el formato estándar de skills (`SKILL.md` y archivos de soporte cuando aplique).
